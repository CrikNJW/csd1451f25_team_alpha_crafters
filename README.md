# Thalassa

Thalassa is a C++ student game where you control a diver and navigate an underwater environment. Team Alpha Crafters built it over ten weeks in a group of five.

Ng Jing Wen worked on the camera, 2D meshes, enemy and environmental hazard logic, the level editor, and game optimization. The [level file input and output changes](https://github.com/CrikNJW/csd1451f25_team_alpha_crafters/pull/1) show one part of that work.

## Open the project

Open the [Thalassa Visual Studio solution](Thalassa/Thalassa.sln) on Windows with the C++ workload installed. Build and run the Thalassa project from the solution. Source files and project assets are under [Thalassa](Thalassa/).
